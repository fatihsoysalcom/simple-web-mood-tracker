# Simple Web Mood Tracker

This example demonstrates a very basic, single-file web-based mood tracker application. It allows users to record their daily mood along with a short note and stores these entries in the browser's local storage. The application then displays a history of recorded moods and a simple summary of mood distribution, illustrating the core concept of tracking emotional patterns over time.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in your web browser.
